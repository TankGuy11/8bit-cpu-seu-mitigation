# Contributing

Thank you for your interest in the 8-bit CPU SEU-mitigation research platform.

## How to contribute

1. Open an issue describing the bug, proposal, question, or documentation improvement.
2. Fork the repository and create a topic branch.
3. Make a focused change, with comments and a relevant testbench where appropriate.
4. Run the applicable simulations and include the commands and observed results in your pull request.
5. Submit a pull request explaining the change, its motivation, and any effect on the research results.

Please do not claim experimental verification that has not been performed. Distinguish simulation from physical FPGA demonstrations and actual radiation testing. Do not include copyrighted third-party materials unless redistribution is permitted.

All contributions must be compatible with the repository's Apache-2.0 license. By submitting a contribution, you agree to license it under that license.

Maintainers review pull requests before merging. Forks and proposed changes do not automatically alter the verified reference implementation.
